# Живая сцена «Фаска Сталь» — пилот

Анимированная сцена на основе статичной фотографии. Движущиеся объекты накладываются
поверх фото отдельными короткими роликами (слоями), склейка происходит в WebGL (three.js).

Открыть: `index.html` через любой локальный сервер, например
`python3 -m http.server` в этой папке, затем http://localhost:8000.

## Как устроено

- `scene/plate.jpg` — исходное фото, с которого убран припаркованный погрузчик (1672×941).
- `scene/original.jpg` — исходное фото без изменений (для сравнения).
- `scene/forklift.mp4` / `.webm` — слой погрузчика: ролик только области движения
  (944×470 px, позиция на фото задана `bbox` в `index.html`).
- `scene/forklift-mask.png` — мягкая маска слоя (альфа-канал).

Ролик слоя начинается и заканчивается кадром, где погрузчика не видно, поэтому повтор
незаметен. Между рейсами плеер делает паузу (`gap`).

## Как добавить слой

1. Убрать объект с фото (или оставить, если он и так «уходит» в здание).
2. Сгенерировать ролик, где первый и последний кадр — фото без объекта.
3. `python3 tools/zone.py clip.mp4 scene/plate.jpg out/` — вырежет область движения,
   подгонит цвет под фото и сделает маску.
4. Добавить запись в `SCENE.layers` в `index.html`.

`tools/loop_full_frame.py` — склейка полнокадрового ролика в бесшовный цикл
с выравниванием яркости (использовался в ранних тестах).
