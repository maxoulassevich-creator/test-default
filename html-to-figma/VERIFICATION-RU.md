# Что и как проверено

Три уровня — их нельзя смешивать:

| Уровень | Что это | Где |
| --- | --- | --- |
| **Реально выполнено** | Chromium 141 (Playwright 1.56.1) на Linux: захват страниц, обход маршрутов, сравнение с настоящим курсором, рендер; запуск собранного `processor.cjs` отдельным процессом; настоящий `ui.html` в изолированном iframe (origin `null`) с настоящим обработчиком по HTTP | `tests/integration/*` |
| **Модель Figma API** | собранный `plugin/dist/code.js` исполняется в Node (vm) поверх строгой модели Plugin API: проверка типов и значений вызовов, `loadFontAsync` перед текстом, диапазоны текста, эффекты, изображения, `createNodeFromSvg`, clientStorage, pluginData. Экспорт модели в PNG — HTML-рендер сцены в Chromium с теми же шрифтами. Это **не** Figma: метрики текста, растеризация и сетевые правила Figma не воспроизводятся | `tests/support/figma-mock.ts` |
| **Не проверено** | настоящая Figma Desktop / веб; Windows (скрипты `.cmd`/`.ps1` не запускались, Edge как браузер захвата не запускался); шрифты конкретного компьютера; политика сети Figma для `http://127.0.0.1` / `http://localhost` | — |

Сборка воспроизводима: `npm ci && npm run build` (esbuild, зависимости закреплены в
`package-lock.json`), установочный ZIP — `npm run package` (фиксированные даты и
порядок файлов, `SHA256SUMS.txt` внутри).

## Проверка в настоящей Figma (10–15 минут)

Это первый шаг после установки: результаты выше получены без Figma.

1. Запустите `start-windows.cmd`, убедитесь, что в окне есть «Код подключения» и строка
   «Браузер: Microsoft Edge …».
2. Figma Desktop → Plugins → Development → Import plugin from manifest… →
   `figma-plugin\manifest.json`. **Проверяется:** Figma принимает manifest
   (`networkAccess` с `reasoning`, `devAllowedDomains`).
3. Новый файл Figma Design → запустите плагин. **Проверяется:** статус «Обработчик найден —
   нужен код подключения» (значит, политика сети Figma пропускает запрос к
   `127.0.0.1:47821` или запасной `localhost:47821`). Если «Обработчик не запущен» при
   открытом окне — это ограничение сети Figma: используйте резервный режим (пакет
   `.h2f.zip` со страницы `http://127.0.0.1:47821`) и сообщите об этом.
4. Введите код → «Подключить» → статус «Обработчик подключён».
5. Загрузите пример `examples\masterskaya.zip` из установочной папки (2 страницы, шрифты
   внутри; шрифты Google есть в Figma) → «Анализировать» → «Создать макеты».
6. **Посмотрите глазами:** два фрейма рядом, без пересечений; тексты редактируются
   двойным щелчком; шрифты верные; на главной одна карточка в позе наведения и курсор
   отдельным слоем; в слоях нет компонентов.
7. «Проверить геометрию» и «Сравнить с исходником» → «Скачать отчёт». Отчёт содержит
   измерения Figma (ширины текстов, отличия пикселей) — по нему видно, насколько
   метрики Figma отличаются от браузера.
8. Повторите «Создать макеты» — новых фреймов быть не должно. Измените текст в одном
   макете, выберите «обновить» → изменённый макет сохранится с пометкой
   «(изменён вручную)».
9. Во время создания нажмите «Отмена» — на холсте не должно остаться слоёв этой попытки.
