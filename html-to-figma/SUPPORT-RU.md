# Что переносится и с какими ограничениями

Обозначения: **✓** — переносится редактируемым слоем; **≈** — переносится приближённо
(с записью в диагностике); **▣** — переносится растром только этого элемента (без
текста внутри; текст остаётся редактируемым); **✗** — не переносится (с записью в
диагностике).

Все геометрические данные — измерения браузера (Chromium/Edge) при выбранной ширине,
а не пересчёт CSS вручную. Глобального Auto Layout нет: фреймы с абсолютными
координатами, как в браузере.

## Источник и страницы

| Возможность | Как | |
| --- | --- | --- |
| Один HTML | загрузка файла | ✓ |
| ZIP: несколько HTML, CSS, JS, картинки, шрифты с относительными путями | безопасная распаковка (без выхода из папки, лимиты размера, CP866-имена) | ✓ |
| SPA с hash-маршрутами (`#/…`), query внутри hash, редиректы | обход ссылок в изолированных профилях браузера, отпечатки содержимого | ✓ |
| Якоря, дубликаты, «страница не найдена», адреса из кода | распознаются и показываются отдельно, не создают лишних макетов | ✓ |
| Указатель страниц профиля проекта | отмечается по умолчанию; обход продолжается дальше и показывает остальное неотмеченным | ✓ |
| Пагинация, календари, бесконечные параметры | пределы: однотипные адреса (12), страницы (80), глубина (4), время | ✓ |
| Состояние приложения (роль, язык, тема в localStorage) | задаётся до запуска страницы; ключи, которые читает страница, предлагаются в UI | ✓ |
| Формы, вход, клики по кнопкам | не нажимаются и не отправляются; обход только по ссылкам | — |

## Геометрия и порядок слоёв

| Возможность | Как | |
| --- | --- | --- |
| Позиции и размеры | рамки браузера в явной системе координат родителя | ✓ |
| `transform` 2D: поворот, перенос, масштаб с `transform-origin` | матрица от точки начала; поворот — вращение слоя; равномерный масштаб — в размеры, кегль, радиусы, тени | ✓ |
| Неравномерный масштаб с поворотом | | ≈ |
| `skew` | без наклона | ≈ |
| 3D-трансформации с перспективой | | ▣ |
| `overflow: hidden/clip/auto` | обрезка фрейма; внутренняя прокрутка — в начальной позиции | ✓ |
| `z-index`, контексты наложения, absolute/fixed вне обрезки | порядок отрисовки браузера | ✓ |
| `position: fixed` | на верхнем уровне макета; в режиме «экран» — закреплённые слои | ✓ |
| `position: sticky` | исходная (непрокрученная) позиция | ≈ |
| Полная высота, lazy-картинки, анимации появления | пробная прокрутка всей страницы, «раскрытая» поза, возврат шапки в исходный вид | ✓ |
| CSS-анимации и переходы | конечные — в конечном кадре, бесконечные — в начальном | ≈ |

| Возможность | Как | |
| --- | --- | --- |
| Строки | переносы ровно как в браузере (явные `\n`), ширина по содержимому | ✓ |

| Подчёркивание / зачёркивание, ссылки | оформление и гиперссылки диапазонов | ✓ |
| `::first-letter` (буквица), `::before`/`::after` с текстом, маркеры списков | отдельные текстовые слои | ✓ |
| `-webkit-line-clamp`, `text-overflow: ellipsis` | обрезка текста Figma | ✓ |

## Известные ограничения

- Результат зависит от браузера и шрифтов компьютера, на котором запущен обработчик:
  на Windows по умолчанию используется установленный Edge, системные шрифты Windows.
- Ширина текста в Figma может немного отличаться от браузера (другая отрисовка глифов);
  переносы строк фиксируются явно, поэтому строки не «переезжают», но правый край
  может сдвинуться на доли пикселя — это видно в «Проверить геометрию».
- Большие страницы с тысячами слоёв создаются медленнее; лимиты узлов и символов на
  страницу задаются в настройках обработчика (`%LOCALAPPDATA%\HtmlToFigma\config.json`).
- Сайты, требующие настоящей авторизации или серверной части, переносятся в том
  состоянии, которое отдаёт локальная копия (внешние запросы по умолчанию разрешены
  только GET, локальная сеть закрыта; кнопка «Не загружать внешние ресурсы» — офлайн).
