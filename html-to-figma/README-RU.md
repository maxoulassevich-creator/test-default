# HTML → Figma: локальный импорт в редактируемые макеты

Плагин для **Figma Design** и локальный обработчик на вашем компьютере. HTML-страница
(или ZIP с сайтом из нескольких HTML, CSS, картинок и шрифтов) открывается в настоящем
браузере, измеряется и переносится в Figma обычными фреймами: текст остаётся текстом с
настоящими шрифтами, фигуры — фигурами, картинки — заливками. Без ИИ, подписок и
внешних сервисов; подходит бесплатный тариф Figma.

Почему нужен обработчик: плагин Figma не может сам открыть страницу в браузере и
измерить её. Это делает обработчик (Node.js + Microsoft Edge / Chrome / Chromium),
который слушает только `127.0.0.1` и пускает плагин по коду подключения.

## Установка и запуск на Windows

1. Распакуйте `HtmlToFigma-1.0.0.zip` в любую папку, лучше с латиницей в пути
   (например, `C:\Tools\HtmlToFigma`).
2. Запустите `start-windows.cmd`.
   - Если Node.js 20+ не установлен, скрипт предложит скачать портативный Node.js 22
     с nodejs.org (~30 МБ, проверка SHA-256) в папку `runtime\`. В систему ничего не
     устанавливается. Можно и самим поставить Node.js LTS с https://nodejs.org.
   - Если Windows SmartScreen спросит про запуск — «Подробнее» → «Выполнить в любом случае».
3. В окне обработчика появится **«Код подключения»**. Окно не закрывайте, пока работаете.
   Браузер подхватывается автоматически: Microsoft Edge (есть в Windows 10/11) или
   Chrome. Если в окне «Браузер: НЕ НАЙДЕН» — запустите `install-browser.cmd`
   (скачает Chromium, ~150 МБ).
4. В **приложении Figma для компьютера** (не в браузере): меню Figma → Plugins →
   Development → **Import plugin from manifest…** → выберите
   `figma-plugin\manifest.json`. Плагины в разработке доступны и на бесплатном тарифе.
5. Откройте файл Figma Design → Plugins → Development → **HTML → Figma (локальный импорт)**.
6. В плагине:
   1. «Код подключения из окна обработчика» → **Подключить** (один раз).
   2. **1. Исходник** — перетащите HTML или ZIP → **Анализировать**. Для первой пробы
      есть `examples\masterskaya.zip` (2 страницы со шрифтами).
   3. **2. Страницы** — отметьте нужные. Страницы, найденные обходом вне указателя
      страниц профиля, помечены «вне указателя» и не отмечены; дубликаты, якоря и
      пределы обхода видны по флажку «показать дубликаты и исключённые».
   4. **3. Настройки** — ширина/высота экрана, схема, состояние приложения
      (значения localStorage: роль, язык, тема), наведение, поведение при повторном импорте.
   5. **Шрифты** — проверяются до изменения холста. Если шрифта нет, создание не
      начнётся; можно явно выбрать замену (она попадёт в отчёт).
   6. **Создать макеты**. Отмена или ошибка удаляют только слои текущей попытки.
   7. **4. Готово** — «Проверить геометрию», «Сравнить с исходником», «Скачать отчёт».

### Если плагин не подключается

- Проверьте, что окно обработчика открыто и адрес в плагине — `http://127.0.0.1:47821`.
- Порт занят другой программой — задайте другой: `set H2F_PORT=47900` перед
  `start-windows.cmd` (тогда этот адрес нужно добавить и в `figma-plugin\manifest.json`).
- Резервный режим без связи плагина с обработчиком: откройте в браузере
  `http://127.0.0.1:47821`, выполните там анализ и скачайте **пакет импорта (.h2f.zip)**,
  а в плагине нажмите «Открыть пакет импорта (.h2f.zip)».

## Что положить в ZIP

Всё, что нужно сайту для открытия без интернета, в тех же папках, что и у вас на диске:

```
мой-сайт.zip
├── index.html        ← главная (если её нет — первый найденный .html)
├── about.html        ← другие страницы (станут отдельными макетами)
├── css/style.css
├── js/app.js
├── img/…             ← картинки (png, jpg, gif, webp, svg, avif)
└── fonts/…           ← файлы шрифтов, если сайт подключает их через @font-face
```

- Папка внутри архива допустима (`мой-сайт/index.html`) — главная найдётся сама; её
  можно сменить в списке «Входная страница».
- Пути в HTML/CSS могут быть относительными (`css/style.css`, `../img/a.png`) или от
  корня сайта (`/css/style.css`).
- Страницы ищутся по ссылкам с главной и по всем `.html` в архиве (до 80 страниц).
- Ресурсы из интернета (Google Fonts, CDN) загружаются, если включён интернет и снят
  флажок «Не загружать внешние ресурсы»; надёжнее положить их в архив.
- Шрифты ещё должны быть в самой Figma (шрифты Google там есть; остальные — установить
  в Windows), иначе плагин остановится до создания слоёв и покажет, каких не хватает.
- Служебное (`node_modules`, `.git`, `__MACOSX`) пропускается. Пределы: архив до 300 МБ,
  до 5000 файлов, один файл до 200 МБ.

## Что получается в Figma

- Одна текущая страница Figma; каждая страница сайта — отдельный обычный фрейм.
  Фреймы стоят сеткой без пересечений (число колонок задаётся), высота ряда — по самому
  высокому макету. Компоненты, варианты, отдельные hover-фреймы и связи прототипа не создаются.
- Полная высота страницы; режим «экран с вертикальной прокруткой» включается кнопкой.
- Поза наведения: одна карточка на странице показана «под курсором» прямо в макете
  (как в исходном CSS), курсор — отдельный слой, его можно удалить.
- Повторный импорт того же проекта: «добавить только недостающие» (в том числе
  восстановить удалённый фрейм на его место), «обновить» (изменённые вами макеты
  сохраняются и помечаются), «создать новую копию рядом».

Подробно — `SUPPORT-RU.md` (что переносится и как, ограничения) и
`VERIFICATION-RU.md` (что и как проверено, а что — нет).

## Шрифты

Figma должна видеть те же шрифты: шрифты Google доступны в Figma сразу, остальные
нужно установить в систему (приложение Figma видит системные шрифты). Плагин проверяет
каждое семейство и начертание (вес, курсив) до создания слоёв, в том числе символы,
которые браузер показал запасным шрифтом (например, кириллицу), и не подменяет
шрифты молча.

## Безопасность

Обработчик слушает только `127.0.0.1`, проверяет заголовок `Host`, пускает плагин по
токену, выданному за код подключения. HTML считается недоверенным: каждая страница
открывается в отдельном профиле браузера, внешние запросы кроме GET и обращения к
локальной сети блокируются, ZIP распаковывается с защитой от выхода из папки и
ограничениями размера. Данные заданий: `%LOCALAPPDATA%\HtmlToFigma` (удаляются через сутки).

## Для разработчиков

```
npm ci
npm run build            # plugin/dist (manifest.json, code.js, ui.html), processor/dist
npm run typecheck
npm test                 # модульные тесты
npm run test:integration # Chromium + модель Figma API (долго: оба блога ~15 мин)
npm run package          # dist/HtmlToFigma-<версия>.zip
npm start                # обработчик из исходников сборки
```

Нужен Chromium: используется установленный Edge/Chrome, `H2F_CHROMIUM=<путь>` или
`node node_modules/playwright-core/cli.js install chromium`.
